# 실시간 상권현황 수집기 — 셋업 가이드 (v2 멀티키)

## 0. 멀티키 전략 (권장)

| 키 수 | 합산 한도(가정 1k/키) | 매시간(1,968건) | 매 30분(3,936건) |
|---|---|---|---|
| 1개 | 1,000 | ❌ | ❌ |
| 2개 | 2,000 | ✅ | ❌ |
| 3개 | 3,000 | ✅ | ❌ |
| **4개** | **4,000** | **✅** | **✅** |

**팀원 4명 각자 본인 명의로 발급 (정책 준수)**
1. data.seoul.go.kr 각자 회원가입
2. 마이페이지 → 인증키 신청 → 즉시 발급
3. 발급된 키를 `scripts/.env` 파일의 `SEOUL_API_KEY_1~4`에 분배

## 1. 의존성 설치
```bash
cd scripts
pip install -r requirements.txt
```

## 2. 키 점검 (등록된 키 모두 정상 작동하는지)
```bash
python collect_realtime.py --check-keys
```
출력 예시:
```
[KEY_1] 광화문·덕수궁 호출 시도
  ✅ KEY_1 정상 작동
[KEY_2] 광화문·덕수궁 호출 시도
  ✅ KEY_2 정상 작동
...
키 풀: 4/4 활성 | 오늘 사용 4/4,000건
```

## 4. 82장소 정확한 목록 다운로드
1. https://data.seoul.go.kr/dataList/OA-22385/F/1/datasetView.do
2. "서울시 주요 82장소 목록.xlsx" 다운로드
3. `raw/` 폴더에 저장
4. 다음 실행부터 자동으로 실제 82장소 사용 (현재는 fallback 75개)

## 5. 매 30분 자동 실행 — macOS launchd (권장, 멀티키 4개 기준)
```bash
SCRIPT_DIR="$(pwd)"  # scripts 폴더에서 실행
PROJECT_ROOT="$(cd .. && pwd)"
sed -e "s|__SCRIPT_DIR__|$SCRIPT_DIR|g" \
    -e "s|__PROJECT_ROOT__|$PROJECT_ROOT|g" \
    com.team7.realtime.collector.plist.template \
    > ~/Library/LaunchAgents/com.team7.realtime.collector.plist
launchctl load ~/Library/LaunchAgents/com.team7.realtime.collector.plist
launchctl list | grep team7

# 중지
# launchctl unload ~/Library/LaunchAgents/com.team7.realtime.collector.plist
```

> 매시간이면 `Minute` 항목 1개(5분), 매 30분이면 2개(5분, 35분) 추가하면 됩니다.

## 6. cron (대안)
```bash
crontab -e
# 매시간 5분
5 * * * * /full/path/scripts/run_hourly.sh

# 매 30분 (5분, 35분)
5,35 * * * * /full/path/scripts/run_hourly.sh
```

## 7. 멀티키 동작 원리
- **장소 분할**: 82장소를 키 4개에 균등 분배 (각 ~21장소)
- **Fallback**: 한 키가 한도 초과(`INFO-200`)되면 다음 키로 자동 전환
- **카운터**: 키별 사용량을 메모리에서 추적, 매 호출마다 콘솔 출력
- **한도 보호**: 키별 `daily_quota`를 .env에서 설정 가능

## 8. 한도 초과 시 자동 동작
1. 키 1이 한도 초과 → 키 1 차단 표시
2. 다음 호출은 자동으로 키 2/3/4 중 잔량 가장 많은 키 사용
3. 4개 모두 초과 시 그 호출만 실패 처리, 다음 호출 시간(다음 시간/30분)에 재시도

## 9. 데이터 활용
- **시계열 분석**: 시간대별 혼잡도/매출 변화, 요일/시간 패턴
- **이상치 탐지**: 평소 대비 급변 (이벤트 발생 신호)
- **분기 모델 검증**: 분기 단위 모델 예측과 실시간 패턴 일관성
- **실시간 데모 모듈**: "지금 푸드트럭이 가야 할 Top-3 장소" 발표용 시연
