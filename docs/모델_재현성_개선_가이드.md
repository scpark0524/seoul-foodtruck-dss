# 모델 재현성 & 정확도·피처 효율 개선 가이드

## A. 직접 돌리면 결과가 달라지나?
**거의 동일하게 재현된다.** 난수는 전부 고정:
- XGBoost `random_state=42`, `tree_method="hist"`(결정적)
- 일자 표본추출 `np.random.default_rng(42)`
- 공간검증 `GroupKFold`(shuffle 없음)

→ **같은 데이터 + 같은 라이브러리 버전이면 숫자까지 동일.**
미세하게 달라질 수 있는 경우(소수점 3~4자리, 결론은 불변):
- xgboost 버전 차이(권장 3.x), numpy/scipy 버전, OS/CPU 차이
- Python 버전(3.11~3.12 권장. 3.14는 일부 패키지 wheel 이슈)

> 즉 R²≈0.90, v2>v1(13배), 입지 드라이버 순위 등 **핵심 결론은 그대로** 나온다.

## B. 정확도 높이기
1. **검증 기준부터 정렬**: 서비스 목표는 '신규 입지 일반화' → **leave-dong-out 공간 CV**를 헤드라인 지표로. (시간 holdout만 보면 과대평가)
2. **하이퍼파라미터 튜닝(Optuna)**: `max_depth, learning_rate(+n_estimators & early stopping), min_child_weight, subsample, colsample_bytree, reg_alpha/lambda`. 공간 CV 점수로 최적화.
3. **결측 처리**: subway~45%, livpop~26%(2023~) 결측 → ① 결측 indicator 컬럼 추가 ② (행정동, 요일/월) 평균 대체. 모델이 '결측 자체'를 신호로 쓰게.
4. **고효율 신규 피처(파생)**:
   - 경쟁강도 = 업종 점포수 / 생활인구 (포화도)
   - 수요밀도 = 생활인구(점심·저녁) / 면적, 오피스성 = 주중/주말 인구비
   - 업종×요일 상호작용, 업종별 요일가중(v2 정밀화)
5. **불확실성 예측**: 분위수 회귀(P10/P50/P90)로 "예상매출 구간" 제공 → DSS 신뢰도↑.
6. **단조 제약(monotone constraints)**: 생활인구·구매력↑ → 매출↑ 등 도메인 제약 → 일반화·신뢰성↑.
7. **최대 레버 = 실시간 결합(C)**: 누적된 `rt_pay_amt`(실거래)를 보조 타깃/피처로 재학습 → 합성 추정매출의 한계 돌파. 데이터가 쌓일수록 정확도 상승.

## C. 피처 효율 높이기 (가지치기)
- 현재 106개 중 상당수가 **저기여**(fac_*, store_* 다수). **SHAP mean|SHAP| 하위 제거 → 상위 30~40개**로 축소:
  - 추론 속도↑, 과적합↓, 해석력↑ (공간 CV 점수는 보통 유지/개선)
- **다중공선성 제거**: 상관 0.95+ 쌍은 하나만(예: store_total vs all_store_cnt).
- 절차: `06`에서 mean|SHAP| 산출 → 누적기여 95% 지점에서 컷 → 재학습 → 공간 CV 비교.

## D. 추천 실행 루프
```
1) 06 실행 → 공간 CV R² 기록(베이스라인)
2) SHAP 하위 피처 컷 → 재학습 → 공간 CV 비교 (효율)
3) Optuna 50~100 trial (공간 CV 목적) → best params (정확도)
4) 파생피처 추가 → 재평가
5) 실시간 누적분으로 rt_* 결합 재학습 (최종 고도화)
```
